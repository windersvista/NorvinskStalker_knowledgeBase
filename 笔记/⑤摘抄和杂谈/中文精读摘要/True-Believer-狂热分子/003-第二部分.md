# 003-第二部分：潜在的皈依者

> 对应原文：true_believer_02_part2.txt（第一章 不受欢迎者 / 第二章 穷人 / 第三章 畸零人 / 第四章 极端自私的人 / 第五章 面对无穷机会的野心者 / 第六章 少数民族 / 第七章 烦闷者 / 第八章 罪犯） | 时间：约 1940 年代末 | 核心人物：托克维尔、希特勒、耶稣、圣伯尔纳、魏茨曼、德瓦莱拉

## 概述

第二部分回答"什么样的人最容易成为忠实信徒"。霍弗开宗明义："一个群体的性格和命运，往往由其最低劣的成员决定。"被遗弃、被排斥的人"本来是建筑师鄙弃的石材，却会成为新世界的奠基石"。他列出心怀不平者的十一类：穷人、畸零人、被遗弃的人、少数民族、青春期少年、有野心的人、被恶德偏执挟制的人、无能者、极度自私的人、对生活厌烦的人、罪犯。

穷人一章最精彩。霍弗区分新穷人与赤贫者：被失意感刺痛的一般是新近陷入贫困的"新穷人"——纳粹和法西斯的主要支持者是破产的中产阶级；反之，为最起码生活操劳的赤贫者"不会有时间、心情去悲愤或造梦"。两条定律：其一，"悲愤会在它几乎得到补偿的时候最为蚀骨"；其二，人不满的程度"跟他与他热切渴望得到之物的距离成反比"。自由会加深失意感，狂热者渴望的是"免于自由的自由"。"瓦解中的集体结构是群众运动萌芽的最佳环境"——启蒙后的犹太人成了自主性最高的个人，犹太复国运动恰在此刻出现。

畸零人分暂时性与永久性两类：青春期少年、失业大学毕业生、退伍军人属前者；永久性的畸零人"只有完全摆脱自我时才会觉得找到救赎"。其余四章简短锋利：极端自私的人"往往是无私精神最勇猛的捍卫者"；面对无穷机会的野心者"无可避免会看不起现在"；行将同化的少数民族中，"最有成就和最没成就的两类人"最易被吸引；烦闷者——运动萌芽最可靠的指标是"一股浓厚的烦闷气氛弥漫"；罪犯——"爱国主义是歹徒的最后归宿"。

## 关键人物

- **托克维尔**：其《旧制度与大革命》研究支撑"悲愤在几乎得到补偿时最为蚀骨"的定律
- **希特勒**：纳粹利用破产中产阶级与烦闷贵妇（"那些渴望冒险、厌于空虚生活，不再能在爱情生活中找到乐趣的上流贵妇"）
- **耶稣**：早期基督教敌视家庭的例证，"因为我来，是叫人与父亲生疏，女儿与母亲生疏……人的仇敌，就是自己家里的人"
- **圣伯尔纳**（St. Bernard）：讲道拆散家庭，被弃之妇多得组成一座女修道院；又号召十字军给罪犯以"得救机会"
- **德瓦莱拉**（De Valera）：爱尔兰独立运动领袖，爱尔兰裔美国人中成就最高与最低者对其呼吁反应最踊跃
- **魏茨曼之母**：名言证明同一犹太家庭可同时出共产党人与犹太复国主义者

## 关键论点 / 金句集

- "一个群体的性格和命运，往往由其最低劣的成员决定。"
- "本来为建筑师鄙弃的石材会成为一个新世界的奠基石。一个没有废料和不满者的国家，固然会井然有序、高尚、和平而愉快，但它缺少开拓未来的种子。"
- "悲愤会在它几乎得到补偿的时候最为蚀骨。"
- "自我若是软弱无力，再多的自由又有何用？"
- "最大声呼吁自由的人，往往是最不乐于住在自由社会里的人。"
- "我们跑得最快、跑得最远的时候，就是逃离自我的时候。"
- "极端自私的人特别容易有失意感……因此，极端自私的人往往是无私精神最勇猛的捍卫者。"
- "爱国主义是歹徒的最后归宿。"
- "群众运动的策略，是要把一种病传染给人，然后又把自己说成治病的药方。"
- "一个有力量的群众运动会培养其追随者的罪恶感。它不但会把人的自主『自我』形容为贫乏和无助的，还会把它说成是罪孽深重。悔罪的方法是抛弃个人的特殊性和独立性，得救的方法是把自我掩埋在团体的神圣一体性中。"

## 背景知识补充

- **圈地运动与克伦威尔新军**：16-17 世纪英国圈地运动把佃农赶出土地，"为克伦威尔的新军充实兵员的，正是这些遭剥夺的群众"，是"新穷人"催生革命的范例。
- **托克维尔悖论**：他在研究大革命前的法国时惊讶发现"在 1789 年大革命之后的每一个阶段，法国的繁荣昌盛都没有高于大革命前的那 20 年"，由此断言革命往往爆发于经济改善而非恶化之时。
- **犹太启蒙运动与隔都**：启蒙运动动摇了犹太教正统与隔都的墙，犹太人"在一夜间发现自己成了孤单的个人"，霍弗认为这是现代犹太人失意感最深的历史根源，也是犹太复国运动兴起的心理背景。
- **墨子和儒家**：提倡"兼爱"的墨子受孔门弟子驳斥，"因为儒家把家庭看得高于一切"，霍弗以此说明中国家庭纽带对群众运动的抑制作用。
- **正统派犹太人与世俗化犹太人**：霍弗认为有紧密社群归属的正统犹太人失意感反而较少，同理"美国南方被隔离的黑人也较北方的自由黑人少些失意感"——共同体纽带是失意感的缓冲垫。

## 关联

- 本部分直接落实作者自序的两个假定：失意感本身足以产生忠实信徒的人格特征；煽动技巧的作用是诱发和强化这些倾向。
- "新穷人"与"悲愤在几乎得到补偿时最为蚀骨"等定律，与第一部分"失意者乐于看到世界急遽改变"互为表里，也是理解当代民粹兴衰的钥匙。
- 早期基督教敌视家庭、圣伯尔纳拆散家庭等例证，为第三部分"把个人同化到集体"提供历史先例。
- 与《乡下人的悲歌》可对照阅读：万斯描写的底层白人群体的愤怒、失业与归属感缺失，正是霍弗笔下的"新穷人"与"失意者"的具体化样本；霍弗则提供了这套心理从个人痛苦到集体狂热的理论管道。
