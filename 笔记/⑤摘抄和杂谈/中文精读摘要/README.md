## 摘要格式约定

每篇摘要（Markdown，UTF-8）：

```
# NNN-章节：中文标题（英文标题）

> 对应原文：Chapter X | 时间：… | 核心人物：…

## 概述        （400-600 字精读级叙事；短书可写 800-1200 字）
## 关键人物    （人物（身份）：作用）
## 关键事件 / 爆料点 （3-8 条，含日期/人名/数字/引语）
## 背景知识补充 （对文中提到的重要事件/人物/名词补充 2-5 条背景说明）
## 金句        （英文原文 + 中文翻译；中文书则摘原文金句）
## 关联        （与前文/史实/本知识库其他书关联）
```

背景知识补充示例：文中提到"伊朗门事件"则补充该事件的背景（是什么、何时、影响）；提到"伊核协议 JCPOA"则简述其来龙去脉。目的是让读者无需另查资料即可理解文中典故。
