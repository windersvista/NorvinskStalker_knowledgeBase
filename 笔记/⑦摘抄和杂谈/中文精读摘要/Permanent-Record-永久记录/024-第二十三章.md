# 024-第二十三章：读取、写入、执行

> 对应原文：第二十三章 读取、写入、执行 | 时间：2012 年末（夜间进行） | 核心人物：斯诺登

## 概述

读取、写入、执行是计算机权限三要素，决定你在一部计算机或网络中的权限范围。斯诺登把这三项当作自己的行动计划：直捣世界守卫最森严的网络核心，查明真相（读取），加以复制（写入），然后公之于世（执行）——同时保证自己不被读取、写入、执行。在 NSA，几乎每一次登录退出、每一次打开、复制、下载、移动或删除档案都会被记录在案，还有网络流动记录、公共重要基建记录，甚至有人开玩笑说摄影机藏在厕所里。但系统的复杂性正是它的弱点：除了系统管理员，没有人确切知道各个系统在哪里重叠、哪里有缺口，"国安局或许为这个网络花了不少钱，但是，像我这样的系统管理员才是真正的拥有者"。在读取阶段，他利用"心跳"（heartbeat）功能自动收集档案——安全日志早已习惯看到心跳，它不会引发警报，成为完美的伪装。他同时了解到盟国 GCHQ（英国政府通信总部）的拖网：光纤神经（OPTIC-NERVE）每五分钟抓取雅虎即时通视频聊天快照，PHOTONTORPEDO 抓取 MSN 实时通用户的 IP 地址。档案先落在夏威夷的服务器上，但他不能在心跳服务器上直接搜索（那会亮起"逮捕我"的信号），于是他把档案导引到"中途站"——坑道里被遗忘的旧戴尔台式机（2009-2010 年机型，可自行储存处理数据、无须连上云端）。他以"测试兼容性"为借口（验证心跳能否在旧版作业系统、民间版上运行）把档案转移到这些机器上，进行搜索、过滤和组织。当他搬着旧计算机回办公桌时，一名反对使用旧机器的 IT 主管拦下他询问用途，他回答："窃取机密。"两人都笑了——这是全书中最接近坦白的一次试探。

## 关键人物

- **斯诺登**：唯一的行动者，利用系统管理员的特权与系统自身的复杂性完成"读取"
- **IT 主管**（无名）：反对使用旧机器的管理员，拦下斯诺登询问用途，得到"窃取机密"的回答

## 关键事件 / 爆料点

- 读取、写入、执行三阶段计划：查明真相、复制、公之于世，同时确保自己不被系统追踪
- NSA 全日志环境：登录退出、档案操作、网络流动、公共重要基建记录均在监控之列
- "心跳"（heartbeat）功能作为档案收集的完美伪装，不会引发警报
- GCHQ 光纤神经（OPTIC-NERVE）：以雅虎即时通视频聊天镜头为目标，每五分钟储存快照
- PHOTONTORPEDO 计划：抓取 MSN 实时通使用者的 IP 地址
- 坑道 2012 年前全面升级为精简型计算机（thin client），数据与处理全在云端
- 废弃的 2009/2010 年戴尔台式机成为档案"中途站"，以"测试兼容性"为借口转移
- "窃取机密。"我回答。我们两人都笑了。

## 背景知识补充

- **读取、写入、执行（read/write/execute）**：Unix/Linux 权限模型的三个基本权限位
- **精简型计算机（thin client）**：无本地存储与处理能力、一切依赖云端的终端
- **心跳（heartbeat）**：周期性自动执行的信号或任务，此处成为档案收集的伪装
- **GCHQ（英国政府通信总部）**：英国信号情报机构，NSA 的五眼联盟伙伴
- **数字绊网（dragnet）**：本章用于描述连接各情报机构路径间铺设的全网监控网
