# 版本选择向导 —— 我该下哪个整合包？

第一次接触诺文斯克整合包系列，看到一排下载链接不知道从何下手？这篇向导帮你快速定位最适合你的那一款。

---

## 按需求快速定位

### 配置较低的老电脑 / 硬件性能有限

**推荐：[《诺文斯克潜行者》 Norvinsk Stalker v1.2.0](./1.Norvinsk%20Stalker%20Download.md)**

基于 SPT 3.7.6，Mod 数量相对精简，对 CPU 和内存的压力最小。这是系列中配置门槛最低的版本，如果你的电脑跑不动后续的 SPT 3.11.4 整合包，这是最稳妥的选择。**注意：该版本已于 2025 年 6 月 29 日停止维护。**

### 想要体验最新 SPT + 最完整的硬核玩法

**推荐：[《生活在诺文斯克》 Live in Norvinsk](./4.Live%20in%20Norvinsk%20download.md)**

基于 SPT 3.11.4，当前主推的旗舰整合包。集成了 150+ Mod，包含伪无缝地图（PathToTarkov）、专属角色 / 商人 / 任务线、Realism 大改、医疗系统重做、AI 行为拟人化、撬锁 / 枪破门等完整玩法。硬核程度最高，沉浸感最强，但对硬件和玩家耐心都有要求。

### 纯萌新 / 第一次玩塔科夫 / 想要接近原版但更友好

**推荐：[《独享的塔科夫》 Exclusive Tarkov](./5.Exclusive%20Tarkov%20download.md)**

同样基于 SPT 3.11.4，但专为新手设计。保留原版塔科夫的核心体验，通过专属起始角色、Mod 武器商人、动态地图、AI 优化等辅助 Mod 降低上手门槛。没有复杂的硬核系统，适合先熟悉地图和基本玩法。

### 想体验硬核但还没准备好直接跳进《生活在诺文斯克》

**推荐：[《现实化诺文斯克》 Realized Norvinsk v0.9.8.1](./3.Realized%20Norvinsk%20Download.md)**

基于 SPT 3.9.8，是《生活在诺文斯克》发布前的过渡版本。硬核程度介于《诺文斯克潜行者》和《生活在诺文斯克》之间，玩法已经具备一定现实化改造，但缺少后续版本的专属商人和任务线等内容。**已停止维护。**

### 只想尝鲜 / 收藏老版本

**推荐：[《诺文斯克潜行者》以往版本下载](./2.Norvinsk%20Stalker%20Previous%20versions%20Download.md)**

包含 v1.1.8 及更早的老版本（最早可追溯到 SPT 3.5.8）。如果出于怀旧或特定需要，可以在此页面找到历史版本的下载链接。

### 想等下一代 / 不着急玩

**关注：[《无法逃离的塔科夫》 Inescapable Tarkov](./6.Inescapable%20Tarkov%20download.md)**

基于 SPT 4.0.x，正在施工中，尚未发布。预计可能需要等到 2026 年下半年。如果不想中途换档，可以关注此页面等发布。
