# 6.塔科夫大事年表：从繁荣到封锁

> 面向玩家的背景阅读材料 | 整理自公开资料 | 2026-08-16

---

塔科夫不是一夜之间变成废墟的。从经济特区到全面封锁，这条时间线走了十几年——而游戏里你看到的每一面断墙，都对应着这条线上的一步。

## 一、世界观时间线（游戏内）

| 时间 | 事件 |
|------|------|
| ~2004 | USEC 与 TerraGroup 建立雇佣关系，逐步成为这家集团的私人军队 |
| 2009 | 化工厂 16 号的土地被非法出售给 TerraGroup 研究所（今天的"工厂"地图） |
| 2015-2018 | 诺文斯克特别经济区繁荣期：免税政策吸引跨国企业，TerraGroup 暗中布局非法研究 |
| 2017-2018 | 俄罗斯政府对 TerraGroup 疑心加重；BEAR 依据秘密法令组建，前苏特种部队军官集结 |
| 2018-2019 | **丑闻爆发**：调查人员挖出隐藏合同与秘密通讯记录；政治对峙持续约六个月 |
| 2019-2020 | **冲突升级**（Contract Wars 时期）：联合国维和部队、俄内务部队、USEC、BEAR 四方卷入；USEC 在灯塔建立进入塔科夫的入口 |
| ~2021 | 塔科夫区域被**最终封锁**：机场关闭、边境设卡、波罗的海舰队封锁海岸；PMC 部分人员滞留 |
| 封锁后 | **游戏开始**：你扮演滞留的雇佣兵，在封锁区求生、任务、寻找出路（游戏时间跨度 2015-2026） |

## 二、游戏内主线（1.0）

1. 塔科夫之旅 → 2. 陨落星辰 → 3. Batya → 4. 意外证人 → 5. 他们已经来了 → 6. 神秘蓝焰 → 7. 探秘"迷宫" → 8. 无名者 → 9. Boreas → 终局：门票（四结局）

（详见 `5.主线剧情全览：逃离塔科夫的路`）

## 三、现实版本演化（对照游戏史）

| 时间 | 事件 |
|------|------|
| 2012 | Battlestate Games 启动开发；核心团队来自前作《Contract Wars》（共同构成 "Russia-2028" 宇宙） |
| 2016-08 | 封闭 alpha 测试开始（预购玩家，签 NDA） |
| 2017-03 | NDA 解除，游戏内容解禁 |
| 2017-07 | 封闭 beta（0.4 起），**删档赛季制开始** |
| 2020 初 | Twitch 促销引爆人气，峰值 20 万玩家同时在线 |
| 2023 | 发布独立竞技模式 EFT: Arena（含战斗通行证） |
| 2024-04 | **PVE 模式上线**（0.14.6.0）——从此多了一个永不删档的选择 |
| 2025-03 | "迷宫"活动上线，因口碑永久保留为正式地图 |
| 2025-08 | 补丁 0.16.9.0 埋下 1.0 预告彩蛋（藏身处小游戏里的 QR 码） |
| **2025-11-15** | **1.0 正式版发布**（同步上架 Steam）：主线章节系统完整、码头与破冰船加入、13 图集齐 |

## 四、删档（Wipe）历史：塔科夫的"时间感"

## 六、给新玩家的一句话时间线

**繁荣（2015-2018）→ 丑闻（2018）→ 战争（2019-2020）→ 封锁（2021）→ 你在废墟里（现在）。**

单机整合包环境没有官方删档压力——PVP 的赛季节奏与你无关，PVE 式的永久进度才是你的游戏方式。
