# 1.逃离塔科夫：背景故事与世界观手册

> 面向玩家的背景阅读材料 | 基于 eftarkov.com、Escape from Tarkov Wiki（Fandom）、Wikipedia 等公开资料整理 | 2026-08-16

---

## 一、这个世界发生了什么？

《逃离塔科夫》的故事发生在一个虚构的地区——俄罗斯西北部的**诺文斯克特别经济区（Norvinsk SEZ）**。

战前，这里是俄罗斯的一块"特区"：为了吸引外资，政府给予区内企业税收减免和特殊法律地位。大量国际公司涌入，其中就包括一家跨大西洋企业集团——**TerraGroup**。经济特区迅速繁荣，两座现代化城市拔地而起：

- **塔科夫（Tarkov）**——区内的物流与交通中心，铁路、港口四通八达。游戏中绝大多数地图都在这里。
- **诺文斯克（Norvinsk）**——特区核心城市，与塔科夫隔着芬兰湾相望，一座大桥连接两城。

但繁荣之下藏着暗流。TerraGroup 名义上做农业生物技术研究，实际在俄罗斯境内从事**非法研究**——隐藏合同、收买官员、秘密实验室。2018 年前后，丑闻爆发，调查人员挖出了大量证据。六个月的政治对峙后，**冲突升级为全面武装冲突**：联合国维和部队、俄罗斯内务部队、以及两家私人军事公司全部卷入。随后，整个区域被**彻底封锁**——机场关闭、边境设卡、波罗的海舰队封锁海岸。

塔科夫从此变成一座孤城。平民要么逃难，要么拿起武器成为**Scav（拾荒者）**。而两家雇佣兵公司——USEC 和 BEAR——则被留在了封锁区内，继续执行各自的使命。

**你，就是其中一员。** 你的目标：活下去，搜刮物资，完成任务——直到找到逃离塔科夫的路。

## 二、谁在打谁？（派系速览）

| 势力 | 立场 | 一句话说明 |
|------|------|-----------|
| **USEC（联合安保）** | TerraGroup 一方 | 西方雇佣兵公司，受雇销毁 TerraGroup 的罪证、保护其财产 |
| **BEAR（战斗遭遇突击团）** | 俄罗斯政府一方 | 由前苏特种部队军官组建，任务是把 TerraGroup 的罪证带出去 |
| **Scav（拾荒者）** | 中立 | 本地幸存者组成的乌合之众，人多势众，见谁抢谁；你也可以扮演他们 |
| **Scav Raiders** | 中立 | 有军事经验的武装团体，活跃在实验室、储备站等高风险区 |
| **Rogues（游荡者）** | 前 USEC | 脱离公司的前 USEC 特工，盘踞在灯塔的水处理厂，重火力据守 |
| **Cultists（邪教徒）** | 中立神秘 | 自称"降临的见证者"，只在夜间活动，用毒匕首无声偷袭 |
| **UNTAR / 俄军** | 封锁方 | 联合国维和部队与俄罗斯武装部队，封锁区域但很少离开基地 |

> 小知识：BEAR 给 USEC 起了个外号叫"Nike"（美国公司），Scav 们则叫他们"游客"（tourists）——毕竟对他们来说，这些雇佣兵都是外来者。

## 三、TerraGroup 到底在搞什么？

这是整个游戏最大的谜团，也是主线剧情的核心。

- **TerraGroup** 是一个跨国控股集团，子公司 40 多家，分支机构遍布 120 多个国家。
- 它的英国子公司 **TerraGroup Labs PLC** 表面上做农业生物技术，实际在塔科夫经营着多处秘密设施：
  - **实验室（The Lab）**——市中心地下的秘密研究中心，官方口径是"这地方不存在"。
  - **迷宫（The Labyrinth）**——承包商 Knossos LLC 建造的"主题公园"，实际上是重兵把守的堡垒（希腊神话主题：米诺陶洛斯的迷宫）。
  - **化工厂 16 号**——2009 年被非法收购的工厂（也就是"工厂"地图的前身）。
- 1.0 剧情揭示：TerraGroup 在策划一个代号"**净化**"的秘密计划，涉及一种叫"蓝冰"的燃料催化剂，还牵扯到一个神秘组织"**无名者**"。

随着主线推进，你会收集到 TerraGroup 的重大罪证——从犯罪录音带到"迷宫"研发报告，一共 9 份（只需集齐 8 份），最终决定自己以哪种方式"逃离塔科夫"。

## 四、商人：封锁区里的人脉

商人是你在这座废城里最重要的盟友。除了买卖装备，他们还是任务提供者：

| 商人 | 他是谁 | 找他干什么 |
|------|--------|-----------|
| **Prapor（普拉波尔）** | 俄军准尉，封锁补给基地的军需官 | 俄系武器弹药、保险；BEAR 的老朋友 |
| **Therapist（治疗师）** | 中央城市医院创伤科主任 | 医疗物资、战后治疗 |
| **Skier（滑雪者）** | 有前科、和海关关系密切的精明商人 | 武器、欧元、灰色交易 |
| **Peacekeeper（和平使者）** | 联合国维和部队补给军官（波兰人） | 西方/NATO 装备，美元结算 |
| **Mechanic（机械师）** | 前化工厂工头，武器改装大师 | 改装件、钥匙卡；主线剧情最大枢纽 |
| **Ragman（破布商人）** | 战前购物中心经理 | 服装、防弹装备 |
| **Jaeger（猎人）** | 自然保护区的前任猎人 | 生存装备；任务以残酷著称 |
| **Fence（围栏）** | 匿名黑市中间商，没人知道他的真名 | 什么都收什么都卖；与 Scav 声望绑定 |
| **Lightkeeper（灯塔管理员）** | 前 USEC 特工，灯塔的守门人 | 战局内交易：护身符、支援服务（需完成专属任务线） |

> 有趣细节：Mechanic 随时可以离开塔科夫（他有外国银行账户和卫星通信），但他选择留下——"因为我爱这门手艺"。

## 五、地图：塔科夫的 13 个战场

| 地图 | 定位 |
|------|------|
| **中心区 Ground Zero** | 商业中心，TerraGroup 总部所在地——一切开始的地方 |
| **街区 Streets of Tarkov** | 市中心，战前的金融心脏，如今是 Kaban 帮的地盘 |
| **工厂 Factory** | 化工厂内部，地图最小、交战最烈 |
| **海关 Customs** | 工业园 + 宿舍楼，冲突早期的主战场 |
| **森林 Woods** | 普里奥泽尔斯克自然保护区，锯木厂是 Shturman 的领地 |
| **海岸线 Shoreline** | 水电站 + 疗养度假村，迷宫入口藏在这里 |
| **立交桥 Interchange** | 公路枢纽 + ULTRA 大商场 |
| **储备站 Reserve** | 秘密军事基地，地下指挥中心与档案库 |
| **灯塔 Lighthouse** | 达利尼角半岛，Rogues 的老巢，Lightkeeper 的家 |
| **实验室 The Lab** | 市中心地下的 TerraGroup 秘密设施（官方不存在） |
| **迷宫 The Labyrinth** | Knossos"主题公园"，重兵把守的地下堡垒 |
| **码头 Terminal** | 巨型货运枢纽，塔科夫最后的疏散点之一 |
| **破冰船 Icebreaker** | 芬兰湾的核动力破冰船，1.0 主线的高潮舞台 |

> 1.0 起大多数地图初始只能通过"转场（Transit）"进入相邻地图，完成主线第一章《塔科夫之旅》后即可自由选择地图。

## 六、主线剧情：逃离塔科夫的路

1.0 版本起，游戏有了完整的主线章节（共 9 章 + 结局分支）：

1. **塔科夫之旅** —— 穿越整座城市，寻找撤离点
2. **陨落星辰** —— 调查森林里坠毁的飞机（一个重要抉择：箱子交给谁？）
3. **Batya** —— 追查 BEAR 派入塔科夫的特种部队
4. **意外证人** —— 一封威胁信引出的罪证
5. **他们已经来了** —— 城中出现的神秘圆圈符号
6. **神秘蓝焰** —— 摩天轮上的爆炸，蓝光闪过，电子设备全灭
7. **探秘"迷宫"** —— 深入 TerraGroup 的地下设施
8. **无名者** —— 追查"净化"计划背后的组织
9. **Boreas** —— 破冰船上的求救信号，塔科夫封锁多年后第一次有人想离开

终局章节《门票》会走向**四个结局之一**：为了全人类 / 灯塔 / 幸存者 / 堕入黑暗——选择权在你手里，而你在前几章做出的抉择（比如那个箱子）会影响你能走哪条路。

> 提示：做剧情任务时一定要带**录音机**！很多剧情文件需要当场阅读/播放才会触发后续目标，忘了的话可以去主界面右下角的【手册】补读。

## 七、术语小词典

- **Raid（战局）**：一局游戏。搜刮、战斗、限时撤离，没撤出去就什么都没有了。
- **PMC**：你扮演的雇佣兵角色（BEAR 或 USEC），死亡会损失装备。
- **Scav**：拾荒者。可以扮演他们免费进场捡垃圾，死亡不掉本体物资。
- **Scav 声望（Fence karma）**：扮演 Scav 时的善恶值。杀 PMC 加分，杀自己人扣分。声望高 → 商人折扣、AI 协助；声望低 → 见面就打。
- **Boss**：地图头目（Reshala、Shturman、Killa、Kaban…），高血量高装备，掉落稀有物品。
- **三狗（Goons）**：Knight、Big Pipe、Birdeye 三人组，社区俗称。
- **藏身处（Hideout）**：你的基地。升级模块（情报中心、工作台、太阳能…）解锁制作、任务与剧情。
- **跳蚤市场**：玩家间交易市场。
- **保险**：死后商人会帮你找回没被捡走的装备（实验室、迷宫除外）。
- **Kappa 容器**：最大的安全箱（3×4），收藏家任务线的终极奖励。
- **删档（Wipe）**：官方 PVP 模式每隔几个月清空一次进度（赛季制）。PVE 模式永不删档。
- **BTR**：装甲运兵车，付费载你撤离或跨图移动。

## 八、赛季与删档：塔科夫的"时间感"

- **PVP 模式**：赛季删档制，一个版本一个赛季（历史上每 4-8 个月删一次档）。删档后所有人从零开始。
- **PVE 模式**：自 2024 年上线以来**从未删档**，进度永久保留。
- **1.0 时代**：新增赛季服专属任务（17 个）与战斗通行证（BattlePass）系统。
- **单机整合包**：没有官方删档压力，进度完全由你自己掌控。
